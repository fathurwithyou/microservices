# M2 — Scalable Distributed System

This document covers the M2 additions. M1 remains the baseline under `docs/IF4031_M1_Laporan.md`.

## Architecture

```text
Client / Media / Field / Ops
        │ HTTP
        ▼
   Client API
        │ gRPC
        ▼
   Aggregator (3 replicas) ── CockroachDB (3 nodes, RF=3)
        │                         │
        │                    leader lease
        ▼
     RabbitMQ
   ├── dashboard-consumer
   ├── notifier-consumer
   ├── critical-notifier
   └── portal-consumer

satellite-ingestor ──► Aggregator
coastal-ingestor   ──► Aggregator
```

## New components

| Component | Responsibility | State |
|---|---|---|
| `satellite-ingestor` | SSE feed, durable offset, fire clustering | offset, detections, fire mapping |
| `coastal-ingestor` | sensor polling, contract validation, quarantine, circuit breaker | quarantine, last good |
| `critical-notifier` | separate critical queue for field alerts | RabbitMQ |
| CockroachDB | Aggregator canonical store | RF=3, TLS |
| PostgreSQL | Auth service only | separate auth_db |

## New contracts

- Sources: `SATELIT`, `SENSOR_PANTAI`.
- Hazard types: `WILDFIRE`, `COASTAL`.
- Scope: `field-reports:write`.
- Client API: `POST /field-reports` → `202 Accepted`, `GET /analytics` for the dashboard.
- Aggregator internal gRPC: `SubmitHazard` for satellite and coastal ingestors.
- Aggregator Audit API:
  - `GET /internal/audit/events`
  - `GET /internal/audit/checksum`
  - `GET /internal/audit/location`
  - `GET /internal/audit/unprocessed`
  - `POST /internal/ops/replay?source=PVMBG`

## Configuration

| Variable | Default | Purpose |
|---|---|---|
| `STORE_DRIVER` | `cockroach` | Aggregator canonical store |
| `AGGREGATOR_COCKROACH_URL` | — | CockroachDB DSN with client cert paths (Kubernetes) |
| `AGGREGATOR_DATABASE_URL` | local DSN | CockroachDB DSN for Compose |
| `AUDIT_TOKEN` | — | Bearer token for Audit API |
| `LEADER_TTL` | `15s` | ingestion leader lease |
| `LEADER_RENEW` | `5s` | lease renewal interval |
| `FEED_URL` | `https://satellite.naufarrel.dev` | satellite SSE feed |
| `FEED_TOKEN` | — | satellite bearer token |
| `SENSOR_URL` | empty | coastal sensor endpoint; empty = fixture mode |
| `SENSOR_TOKEN` | — | coastal bearer token |
| `SATELLITE_DATABASE_URL` | local Cockroach DSN | durable offset/detection/fire state |
| `COASTAL_DATABASE_URL` | local Cockroach DSN | durable quarantine/last-good state |

All other M1 variables remain in `.env.example`.

```bash

make generate

make compose-up

# M2 services (requires FEED_TOKEN; SENSOR_URL is optional)
docker compose --env-file .env --profile m2 up --build

# Audit smoke
AUDIT_TOKEN=... AGGREGATOR_URL=http://localhost:8090 ./scripts/m2-smoke.sh
```

## Cluster deployment

```bash
kubectl apply -k deploy/kustomize/overlays/cluster
kubectl -n sistem-informasi-kebencanaan-bnpb wait \
  --for=condition=complete job/cockroachdb-certs --timeout=180s
make m2-smoke
```

The cert Job writes cert keys into `bnpb-secrets`. Run it before expecting
CockroachDB pods to become Ready.

## Observability endpoints

Every HTTP/health server exposes `/metrics`. Aggregator and Client API emit
server spans; gRPC calls between Client API, Aggregator, and Auth are traced.
The Compose stack leaves tracing disabled unless an OTLP endpoint is supplied.

## Known limits

1. `satellite-ingestor` and `coastal-ingestor` use durable pgx state when their
   `*_DATABASE_URL` is set; the in-memory adapter remains the test/fixture fallback.
2. Field reports are durably accepted and an asynchronous worker moves them to
   `processed`; the downstream side effect is still a no-op.
3. Park/replay is implemented for PVMBG and BMKG mapping failures; malformed
   transport payloads still depend on the source client returning a mapping error.
4. Critical coastal events are routed to `hazard.events.critical` and consumed by
   `critical-notifier`; end-to-end latency is not measured yet.
5. Client API reserves 80% of in-flight capacity for Field Team/raw-scope clients
   and 20% for Media; Media receives 429 with `Retry-After` when its class is full.
5. CockroachDB cert rotation is manual.
6. The cluster overlay expects a `local-path` StorageClass.
7. Metrics are exposed at `/metrics`; OTLP tracing activates when
   `OTEL_EXPORTER_OTLP_ENDPOINT` is set. The demo stack points it at the
   collector in `observability.yaml`.

These limits are tracked in the M2 implementation plan. They must be closed
before the final demo.
